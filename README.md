# Бал → ECTS

Невелика вебсторінка, яка переводить бал за 100-бальною шкалою в оцінку ECTS. Вводите бал — одразу бачите оцінку.

## Шкала

| Бал | Оцінка ECTS |
|---|---|
| 90–100 | A |
| 82–89 | B |
| 74–81 | C |
| 64–73 | D |
| 60–63 | E |
| 35–59 | FX |
| 0–34 | F |

Бал поза межами 0–100 або не число вважається помилкою.

## Структура

```
site/
  index.html        сторінка
  grade.js          логіка переведення: функція toEcts(score)
tests/
  grade.test.js     автоматичні тести
.github/workflows/
  ci-cd.yml         конвеєр CI/CD (GitHub Actions)
package.json
```

Зовнішніх залежностей немає: сторінка — чисті HTML і JavaScript, тести написані на вбудованому в Node.js модулі `node:test`.

## Запуск локально

Сторінка використовує JavaScript-модулі, тому її треба відкривати через локальний сервер, а не подвійним кліком по файлу:

```bash
python3 -m http.server -d site
```

і відкрити http://localhost:8000.

## Тести

Потрібен Node.js 20 або новіший.

```bash
npm test
```

Тести перевіряють межі кожної оцінки (наприклад, 89 → B, 90 → A) і те, що неправильний бал відхиляється.
